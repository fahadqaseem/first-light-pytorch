# First Light · PyTorch

**My first neural network, from a single sandal to a clothing classifier.**

A learning project for **CSC 5991: AI for Augmented and Virtual Reality**, taught by Prof. Zhizhong Han at Wayne State University. I used Fashion-MNIST to learn the complete workflow: inspect data, build a model, calculate loss, update weights, and evaluate predictions.

## Why I chose this project

I chose **PyTorch** because I want to use it in my research and future AR/VR work. For this exercise, I ran locally on my MacBook using its Apple GPU through PyTorch’s MPS backend.

My initial ideas were fitting a curve, finding a hidden shape, and classifying clothing. I picked **“T-shirt or sneaker?”** to keep the first experiment manageable. Learning an occupancy function—whether a spatial point is inside or outside a shape—remains an idea for later. My iPhone scanning project is separate from this homework.

## Results from my completed session

| Experiment | Training images | Epochs | Test accuracy |
| --- | ---: | ---: | ---: |
| Initial baseline | 60,000 | 3 | 79.41% |
| Continued baseline | 60,000 | 6 total | 82.37% |
| Validation-selected model | 48,000, plus 12,000 for validation | 30; best at 30 | 84.50% |

The baseline gained **2.96 percentage points** after three more epochs. The separate validation-selected model gained **2.13 percentage points** over the six-epoch baseline, with a final test loss of **0.4347**. All test accuracies use the 10,000-image test set.

**What happened at epoch 30?** Training loss reached **0.3903** and validation loss reached **0.4139**, the lowest validation loss in the run. I configured a five-epoch patience rule, but it **did not trigger**: training ended at the 30-epoch limit. The model restored the best weights, which happened to be from epoch 30. This is a useful result, not proof that the model has reached its best possible performance.

## What I built

- **Data:** Fashion-MNIST, 28 × 28 grayscale images in 10 clothing categories.
- **Model:** flatten → 784 inputs → 32 hidden neurons → ReLU → 10 output scores.
- **Training:** cross-entropy loss, SGD with learning rate 0.01, and batches of 64.
- **Device:** Apple MPS when available, otherwise CPU.
- **Extension:** a fresh model, a reproducible 48,000/12,000 training-validation split, and validation-based weight selection with a maximum of 30 epochs.

The baseline begins with a one-image update before dataset training. The extension starts from fresh weights because the baseline already saw all 60,000 training examples.

## What I learned

1. **An image becomes numbers.** Each image has 784 pixel values; tensor conversion scales this dataset’s byte-valued pixels to 0–1.
2. **Ten scores mean ten candidate categories.** The hidden-layer width is a choice, while the output size follows the number of classes. The scores are logits, not probabilities.
3. **A forward pass predicts; training updates weights.** The cycle is clear gradients → predict → calculate loss → backpropagate → optimizer step.
4. **Loss and accuracy answer different questions.** Loss evaluates the scores; accuracy counts correct class predictions.
5. **Evaluation still needs forward passes.** `eval()` selects evaluation behavior, and `no_grad()` disables gradient recording. Neither performs an optimizer update.
6. **Validation guides model selection.** Training data updates weights; validation data helps choose the checkpoint; test data is for reporting performance.
7. **More training is not an unlimited guarantee.** Validation trends, compute time, and the task’s needs inform when to stop. A target such as 99.9% needs evidence, not just more epochs.

## How to read or run it

Open [the annotated notebook](first-light-pytorch.ipynb) to follow the experiment and see the saved outputs. Each code cell has an explanation immediately above it.

For a fresh local setup, from the project folder:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install torch torchvision matplotlib ipykernel
```

Open the notebook in VS Code with the Python and Jupyter extensions, select the `.venv` interpreter as its kernel, and run from top to bottom. The first data-loading cells download Fashion-MNIST into `data/`. The notebook and README live in the project folder, outside `.venv`.

My saved session used Python 3.13.3, PyTorch 2.14.0, and Torchvision 0.29.0. The commands above install the versions available in your environment; they do not pin an exact reproduction. Seeds help repeatability, but hardware, versions, and execution order can change results. Rerunning a continuation-training cell keeps updating its current model.

## How I interpret the comparison

This is an exploratory learning exercise. I inspected the test set during the baseline experiment. The extension uses a different initialization, fewer fitting images, and more epochs, so its accuracy change cannot be attributed to early stopping alone. For a controlled follow-up, I would fix the split and initialization, change one setting at a time, and reserve test evaluation until choices are complete.

A small convolutional network could be a future experiment because it can learn local image patterns. For this homework, I stopped after documenting the complete workflow and the validation-selected result.
